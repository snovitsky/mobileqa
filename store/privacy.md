# Политика конфиденциальности Brandmaker QA

Дата редакции: 19 октября 2026 года. Издатель: Brandmaker. Контакт: [info@brandmaker.ru](mailto:info@brandmaker.ru).

Brandmaker QA — расширение Chrome для сравнения сайтов в нескольких размерах экрана, синхронизации действий и поиска возможных проблем вёрстки. У расширения нет собственного сервера сбора данных, рекламной аналитики и системы учётных записей.

## Какие данные используются

Для работы расширение использует адрес и название выбранной вкладки, адрес проверяемого сайта, сведения о размерах экранов и действия в подключённых страницах: нажатия, прокрутку, переходы и изменения обычных полей ввода. При включённой синхронизации эти действия передаются между подключёнными страницами локально в вашем браузере. Обычные значения полей могут обрабатываться для повторения ввода.

Парольные поля и выбор файлов исключены из предусмотренного расширением повторения ввода. Это не гарантирует распознавание любых нестандартных форм и редакторов сторонних сайтов. Не используйте синхронизацию для ввода конфиденциальных данных или выполнения реальных покупок и отправок, если повторение такого действия нежелательно.

Для проверки вёрстки локально анализируются размеры, видимость и расположение элементов. Результаты могут содержать текстовые обозначения элементов, адрес страницы и CSS-селекторы.

## Хранение и передача

Настройки экранов, масштаба, калибровки и поведения панели сохраняются в локальном хранилище расширения. Служебное состояние подключённых вкладок, временные токены и данные сеанса используются внутри браузерной сессии. Разрешения сайтов хранит Chrome; подсказки адресной строки строятся из уже выданных разрешений без обращения к полной истории посещений.

Расширение не отправляет эти сведения на сервер Brandmaker и не продаёт их. При открытии сайта Chrome обращается к самому сайту и его ресурсам. Сайт может использовать ваши cookies, существующую авторизацию и собственные средства аналитики согласно своей политике. Макеты не являются отдельными изолированными браузерными профилями.

По вашей команде можно скачать отчёт о вёрстке или файл диагностики. Они могут содержать адреса страниц, параметры адресной строки, сведения о размерах, состоянии экранов, обозначения элементов и события сеанса. Файлы не отправляются автоматически. Перед пересылкой проверяйте, нет ли в адресах или текстах конфиденциальной информации. Если вы сами направляете файл или письмо в поддержку, Brandmaker получает предоставленные вами сведения для ответа и разбора обращения; не присылайте пароли, cookies и ключи доступа.

## Разрешения и управление

Разрешение tabs используется для определения адресов вкладок рабочего окна. Оно не даёт само по себе права читать содержимое всех сайтов. Доступ к конкретному сайту запрашивается отдельно для загрузки и синхронизации его страниц. Вы можете отозвать его через настройки Brandmaker QA → «Доступ к сайтам» либо через управление расширениями Chrome. Остановка сеанса и отзыв доступа — разные действия.

Режим «Разрешить встраивание» временно меняет защитные заголовки ответа выбранного сайта для встроенных экранов вкладки панели. Это помогает показывать сайты, запрещающие iframe, но может ослабить их ограничения внутри этих экранов. Режим управляется в настройках; обычные вкладки сайта этим правилом не изменяются.

Настройки и локальные данные расширения можно удалить, удалив расширение из Chrome. Скачанные вами файлы и отправленные обращения удаляются отдельно. Для вопросов о предоставленных поддержке данных обращайтесь на info@brandmaker.ru.

Использование сведений, полученных через возможности Chrome, ограничено описанными пользовательскими функциями и поддержкой их работы. Эти сведения не используются для рекламы, продажи данных или определения кредитоспособности. При изменении обработки данных эта политика будет обновлена; существенные изменения должны сопровождаться понятным уведомлением.
