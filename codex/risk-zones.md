# Риски и ограничения реализации

Выводы ниже основаны на чтении кода, а не на воспроизведении в Chrome.

| Зона | Факт и следствие |
|---|---|
| Password | Исправлено в текущих исходниках: bridge и desktop-source исключают password/file при capture/apply. Регрессия проверяет отсутствие передачи из телефона в peers и основную вкладку. |
| Реальные действия | `bridge.js` защищает стандартные submit и синхронную отправку во время replay/400 ms mute. Произвольные click/input handlers и отложенные запросы сайта могут выполняться на каждом зеркале. |
| Заголовки | `background.js/prepare` удаляет всю CSP, CSP-report-only и X-Frame-Options для подходящих sub_frame-ответов host в panel tab. Это меняет условия работы страницы, а не только frame-ancestors. |
| Постоянство доступа | Stop снимает rules/session, но не permissions и не регистрацию content scripts. Новые совпадающие iframe получают script до конца browser session; обычный top frame bridge сразу покидает. |
| Origin/host | Проверки сессии сравнивают hostname, а permission match включает protocol; порт не отражён в match. Не обещать полную origin-изоляцию на основе hostname. |
| DOM-различия | Поиск эвристический, зависит от id/tag/text/link/image/classes; canvas, shadow DOM, разные mobile/desktop структуры и synthetic event handlers могут не поддерживаться. |
| Навигация | URL опрашивается раз в 250 ms. История карточки дополняется на ready, не на route, поэтому «Назад» не равен browser history для SPA. Автовыравнивание ограничено подготовленным origin. |
| Две панели | Background допускает несколько sessions, но desktop-source хранит один token. Поведение двух панелей с одним источником требует отдельной проверки. |
| Переключение источника | Если prepare выполнен без sourceTabId, последующее включение follow-source вызывает resync-source без переподготовки и получает «Нет подключённой основной вкладки». Для подключения требуется снова «Показать»; вывод по panel.js/background.js, без browser-воспроизведения. |
| Общий профиль | Реальные сайт/аналитика/сессии загружаются на всех экранах. iframe cookies могут ограничиваться браузером. Расширение не блокирует аналитику сайта. |
| Диагностика | Отчёт не включает values событий input, но сохраняет URL и selectors. URL query и id могут содержать чувствительные сведения. |
| Тайминги/очереди | До 80 pending events на карточку; лишние события отбрасываются, readiness timeout 10/12 s. Нет универсальной гарантии воспроизведения каждого действия. |
| Имитация устройств | Применяются только width/height CSS. dpr/platform/rank профиля не эмулируют устройство, браузер, OS или user agent. |

Дефекты зафиксированы, исправления не входят в инициализацию документации.

## Инструменты разработки после обновления main

Браузерные тесты и CI теперь существуют, но их наличие не доказывает устранение password/custom side effects/многопанельных рисков: соответствующие сценарии полностью не покрыты. scripts/check.cjs проверяет имена файлов на analytics-маркеры, не выполняет полный анализ содержимого на интеграции/секреты. Прямой push не блокируется обязательными remote checks по правилам workflow, поэтому локальные npm test/build остаются значимым gate. Реальные GitHub settings и CI results здесь не проверялись.

Двустороннее управление: разные desktop/mobile DOM могут дать missing; семантическое совпадение не гарантируется. Единый выключатель прекращает дальнейшую передачу, но не отменяет уже выполненные действия сайта. Source навигация ограничена выбранным host.
