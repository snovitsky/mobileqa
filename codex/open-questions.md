- 2026-10-19: пользователь повторно сообщил о размытии мелкого текста кнопок внутри landscape iPad при физическом масштабе 100%. На предоставленной странице кнопки содержат текст 12 px; у проверенных кнопок и трёх ближайших контейнеров нет filter/transform. На простом локальном fixture тот же дефект не подтверждён. Требуется воспроизведение именно внутри панели и сравнение растеризации; фактическую причину нельзя считать установленной. Браузерный инструмент запрещает чтение пользовательских chrome-extension страниц; запрет не обходить. Формулу физической калибровки и viewport по гипотезе не менять.

1. Подтвердить реальное поведение Chrome (включая Chrome 118) ручным smoke; при инициализации browser run не проводился.
2. Исключение password/file реализовано в bridge и desktop-source capture/apply. Локальная desktop-регрессия проверяет trusted ввод password/file в обоих направлениях и authenticated apply с поддельным типом поля; это не покрывает произвольные нестандартные редакторы и обработчики сайта. Результаты дополнительных проверок — в checks.md. Отдельно остаётся риск побочных эффектов произвольных обработчиков сайта (пункт 3).
3. Проверить возможное дублирование побочных эффектов custom handlers и определить продуктовую границу безопасного зеркалирования.
4. Проверить две панели с одним sourceTabId, закрытие/повторную подготовку, динамическую смену домена и восстановление service worker.
5. Определить ожидаемое поведение «Назад» для SPA и следования desktop source; текущая история не является полной browser history.
6. Явный отзыв permissions/content scripts реализован отдельно в настройках 2.6.15; Stop по-прежнему только останавливает сеанс. Реальный smoke отзыва через пользовательский Chrome остаётся ручной проверкой.
7. ZIP-сборка, CI artifact по SHA и теги vX.Y.Z теперь описаны; процесс публикации в магазине и наличие опубликованных releases отдельно не проверены. База main проверена как 09668b2 2026-10-19; настройки remote protection известны только по зафиксированным правилам workflow.

Локальные fixtures не закрывают совместимость произвольных обработчиков сайта, одновременных панелей и восстановления service worker. Проверки полей и побочных эффектов оценивать по конкретным сценариям, не по одному общему PASS.
