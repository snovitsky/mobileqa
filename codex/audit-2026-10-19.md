# Аудит приложения и документации — 2026-10-19

Область: текущие незакоммиченные изменения на main, версия 2.6.15. База HEAD/origin/main — 09668b2, после fetch расхождений нет. Аудит охватывает весь собственный runtime extension/, scripts/, package/lock, tests/, CI и codex/. Сторонние зависимости не подвергались независимому исходному аудиту; рабочие сайты и клиентские формы для автоматических действий не использовались. Коммит и push не выполнялись.

## Оставшиеся ограничения

Размытие, реальный smoke в пользовательском Chrome/Chrome 118, произвольные побочные эффекты обработчиков сайта, несколько панелей одного источника и восстановление service worker остаются в open-questions/risk-zones. CSS viewport не эмулирует Safari/OS/UA/аппаратный DPR. Снятие CSP относится ко всей политике подходящего sub_frame, не только frame-ancestors. Stop не отзывает ранее выданные host permissions. История карточки хранит адреса, а не полное состояние браузерной истории/форм.

Кодовые guards исключают password/file из capture/apply в обоих content scripts. Расширенные локальные проверки находятся в desktop.cjs; итог их исполнения и остальные реально выполненные команды зафиксированы в checks.md. Полный успешный прогон не является доказательством отсутствия ошибок на любых внешних сайтах.

Результаты финальной проверки текущего состояния — [checks.md](checks.md). Исторические результаты предыдущих версий не заменяют этот прогон.
