# Стиль кода

Текущий код компактный, с короткими именами и множеством выражений на строке. panel/background используют ES modules, bridge/desktop-source — IIFE для внедрения на страницы; panel.js содержит top-level await. CSS содержит последовательные переопределения одних селекторов.

Новые scripts/ и tests/ используют CommonJS .cjs и Node.js 22+; браузерные fixture встроены строками в тесты. Не менять формат модулей extension ради Node-инструментов. Большой рефакторинг выделять отдельно согласно codex/workflow.md.

При дальнейших изменениях сохранять локальные интерфейсы и простой vanilla JS, но писать читаемые имена и небольшие функции. Не воспроизводить плотность исходников ради формального единообразия. Избегать массового форматирования вместе с исправлением поведения.

Использовать существующие normalizeURL, send/relay/trace и cleanup/serial там, где они подходят. Не добавлять архитектурные абстракции без упрощения поддержки. Функции describe/find в двух content scripts существенно дублируются, но find в desktop-source.js не вызывается: replay есть только в bridge.js. Изменение описания событий требует проверки обоих режимов; извлечение общего модуля должно учитывать формат внедряемых скриптов.

Новые комментарии на русском, только для неочевидных ограничений, причин решений и обходов. Старые английские комментарии не менять механически. Решения с долгосрочным значением отражать в [decisions.md](decisions.md).
