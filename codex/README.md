# Рабочая документация Brandmaker QA

Актуализировано 2026-10-08 на базе `26ccf12` из origin/main. Область — один репозиторий `mobileqa`; продукт — Chrome extension версии 2.6.3, Manifest V3, minimum Chrome 118 по manifest. Вся подробная документация и справочная информация хранится здесь, в codex/. Корневой README — краткий вход для пользователя, AGENTS.md — обязательные правила агента. Отдельных CONTRIBUTING и PROTOCOL больше нет: их сведения объединены с профильными документами.

Начать с [индекса контекста](context-index.md), [карты проекта](project-map.md) и [порядка работы](workflow.md). Документы описывают фактический код; подтверждение поведения в Chrome отдельно от чтения исходников.

DevDependencies: Playwright 1.62.1 и fflate 0.8.3, Node.js 22+. Работа ведётся только в main; прямой push требует предварительного подтверждения и локальных проверок, PR не обязателен.
