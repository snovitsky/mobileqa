# Рабочая документация Brandmaker QA

**Передача магазина следующему разработчику:** начать с [раздела передачи в плане](store-release-plan.md#передача-следующему-разработчику-и-codex--начать-отсюда), затем [setup](../store/setup.md), [карточки](../store/listing.md) и [аудита](store-security-review.md). По решению владельца сейчас поставляются код и документы в main. Ответственный за Store ещё выбирается; staging/Cloud/карточку в этой передаче не создаём, публикация заблокирована в store/release-state.json. План включает готовые части, оставшиеся действия по порядку, ветки/CI/notes, activation gates и краткое поручение следующему Codex.

Актуализировано 2026-10-19 на базе `76f7855`; текущая поставка кода/документации — 2.6.20, без публикации в магазине. Область — один репозиторий mobileqa; Chrome Manifest V3, minimum Chrome 118 по manifest. Вся подробная документация и справочная информация хранится здесь, в codex/. Корневой README — краткий вход для пользователя, AGENTS.md — обязательные правила агента. Отдельных CONTRIBUTING и PROTOCOL больше нет: их сведения объединены с профильными документами.

Начать с [индекса контекста](context-index.md), [карты проекта](project-map.md) и [порядка работы](workflow.md). Документы описывают фактический код; подтверждение поведения в Chrome отдельно от чтения исходников.

В 2.6.13 Main следует активной вкладке рабочего normal-окна независимо от повторения действий; tabs согласовано для чтения адресов текущих вкладок, без API полной истории. Собственный viewport вынесен в responsive.js; настройки размеров сохраняются. Результаты текущих регрессий — только в checks.md; размытие кнопок не объявлено исправленным.

Закрываемые ошибки, время и видимый счётчик повторений вынесены в error-notice.js; pointer-жест отменяется при выходе за экран/потере фокуса. Play/Stop имеют явное состояние. Контракты missing/cancel-pointer и ограничения описаны в api-map/frontend/risk-zones.

В 2.6.14 индикатор приложения отделён от серьёзности сообщения, видимые подписи сеанса убраны. Responsive-рамка меняет размер ручками/клавиатурой без числовых inputs; preferences записываются по завершении drag. Исправлено лишнее внутреннее скругление .screen; размытие не объявлено устранённым. На том этапе protocolVersion:1, ZIP содержал 17 путей.

В 2.6.15 состояние основной вкладки перепроверяется после навигации и во время ожидания загрузки, чтобы запоздалый loading не оставался после ready. Индикатор учитывает готовность встроенных экранов и отличает подключение, частичную готовность и отсутствие подключённых экранов после таймаутов. Фактические результаты проверок — в checks.md; изменение цвета не доказывает исправление всех возможных сбоев сайта.
