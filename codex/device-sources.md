# Стартовые профили — 4 октября 2026

Ниже сохранены исходные основания выбора профилей из прежнего справочника extension/. Внешняя статистика при переносе 2026-10-08 не перепроверялась; заявления источников не следует считать новым независимым исследованием проекта.

Ниже приведены базовые размеры полного прямоугольника дисплея из extension/devices.js в CSS px, а не неизменный viewport сайта. Панель вычитает высоту декоративных системных и браузерных панелей; фактический viewport указан под выбором устройства и зависит от режима панелей и поворота. Сравнивать с DevTools нужно именно фактический viewport. Это не полная эмуляция аппаратного устройства или Safari. Android viewport на реальном устройстве также зависит от масштаба интерфейса и настроек браузера.

- iPhone 11: 414 × 896 CSS px. Самая распространённая модель в сети МегаФона (апрель 2026).
- Xiaomi Redmi Note 13: 393 × 873 CSS px, ориентир для проверки адаптивной вёрстки. Одна из наиболее распространённых моделей Xiaomi по данным МегаФона.
- Samsung Galaxy A12: 360 × 800 CSS px. Одна из наиболее распространённых моделей Samsung по данным МегаФона.
- Apple iPad 11 (2025): 820 × 1180 CSS px. Лидер продаж планшетов по выручке за I квартал 2026 по данным М.Видео. Это НЕ статистика интернет-использования.

Открытого достоверного рейтинга всех моделей по использованию в российском интернете не найдено. Данные сети одного оператора не равны доле всего российского интернета; продажи не равны установленной базе. Поэтому интерфейс не объявляет эти четыре устройства абсолютными лидерами России.
