## Реализованные решения продукта

- MV3 service worker управляет разрешениями и сессиями; panel исполняет интерфейс и маршрутизацию, content scripts работают у DOM сайта.
- CSS viewport в живом iframe позволяет проверять адаптивную вёрстку без debug protocol и служебной вкладки на устройство. Ограничение — нет аппаратной/браузерной эмуляции.
- Основная вкладка — односторонний источник; автономная панель выбирает лидера по взаимодействию. Токен сессии и проверки отправителя связывают сообщения с проверкой.
- Host access запрашивается при пользовательском запуске, режим изменения заголовков применяется к panel tab и выбранному host.
- Неоднозначный DOM match обычно отклоняется вместо произвольного клика; стандартный submit не зеркалируется.
- Basic не содержит логики Metrica/Brandmaker Analytics; это подтверждается текущими исходниками и README. Мотивы прежних изменений сверх записанных в Git/README не установлены.
