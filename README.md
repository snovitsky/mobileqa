# Brandmaker QA 2.6.17

Расширение Chrome для проверки адаптивной вёрстки на 3–5 живых экранах с синхронизацией действий. Работает локально, без интеграций с внешними системами аналитики. Проверяет CSS-размеры в Chrome; аппаратные устройства и Safari не эмулирует.

Загрузите папку `extension/` в режиме разработчика на `chrome://extensions`, откройте сайт и нажмите значок расширения. В панели нажмите ▶ и разрешите доступ к домену.

«Основная» следует активной вкладке рабочего окна Chrome; «Синхронизация» отдельно управляет повторением действий. Для своего viewport выберите «Отзывчивое устройство» и потяните его правую, нижнюю границу или угол. Размеры и процент масштаба также редактируются прямо в строке под выбором устройства. Разрешение tabs используется для адресов текущих вкладок; полная история посещений не собирается, доступ к сайтам разрешается отдельно.
