# Brandmaker QA 2.6.3

Расширение Chrome для проверки адаптивной вёрстки на 3–5 живых экранах с синхронизацией действий. Работает локально, без интеграций с внешними системами аналитики. Проверяет CSS-размеры в Chrome; аппаратные устройства и Safari не эмулирует.

Загрузите папку `extension/` в режиме разработчика на `chrome://extensions`, откройте сайт и нажмите значок расширения. В панели нажмите «Показать» и разрешите доступ к домену.
